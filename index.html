🔑 Das Datenschutz-Prinzip

Der Manager-Agent sanitisiert Briefings, bevor kostenlose Worker loslegen: Firmennamen, KPIs und Personen werden entfernt. Die Worker erhalten nur anonymisierte Problem-Profile – nützlich genug für gute Ergebnisse, sicher genug für echte Daten.

So bauen wir es auf

In vier Schritten zu deinem eigenen KI-Betriebssystem. Wir machen das zusammen.

1

Server-Setup (Hetzner)

Wir richten einen eigenen Linux-Server ein – Docker, SSH, Firewall. Du bist der einzige mit Zugriff.

# Hetzner Cloud Server erstellen (CX22, ~5 €/Monat) ssh root@dein-server apt update && apt install docker.io docker-compose docker run -d --name n8n -p 5678:5678 n8nio/n8n
2

Hermes Agent + OmniRoute

Hermes als KI-Agent-Framework installieren. OmniRoute als kostenlosen Gateway für 115+ Modelle ohne API-Key.

npm install -g omniroute # kostenloser KI-Gateway omniroute # startet auf :20128 hermes -p workers config set model.base_url http://localhost:20128/v1 hermes -p workers config set model.default oc/deepseek-v4-flash-free
3

Obsidian Vault + N8n Workflows

Dein Wissensspeicher als Markdown-Dateien. N8n verbindet Hermes mit Postfach, Kalender, Notion – automatisierte Workflows, die 24/7 laufen.

# Obsidian Vault auf dem Server (Git-Sync mit lokalem Rechner) git init ~/vault && git remote add origin ssh://... # N8n Workflow: E-Mail → Hermes → Obsidian → Telegram-Push
4

Agenten aktivieren (24/7)

Cron-Jobs für Mitbewerber-Beobachtung, Content-Ideen, Lead-Recherche. Der Gateway feuert automatisch – du bekommst Ergebnisse per Telegram.

hermes -p workers cron create "0 7 * * 1-6" "Mitbewerber-Scout..." --deliver telegram hermes -p workers gateway install hermes -p workers gateway start
